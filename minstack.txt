155. Min Stack
Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.

Implement the MinStack class:

MinStack() initializes the stack object.
void push(int value) pushes the element value onto the stack.
void pop() removes the element on the top of the stack.
int top() gets the top element of the stack.
int getMin() retrieves the minimum element in the stack.
You must implement a solution with O(1) time complexity for each function.

Example 1:

Input
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

Output
[null,null,null,null,-3,null,0,-2]

Explanation
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin(); // return -3
minStack.pop();
minStack.top();    // return 0
minStack.getMin(); // return -2

Constraints:
-231 <= val <= 231 - 1

--->min stack code can be implemented by two stacks.
--->we can implement either by single stack or two stacks this problem.

-----bruteforce approach------
class MinStack {
    
    Stack<int[]>st=new Stack<>();
   
    public MinStack() {
        
    }
    
    public void push(int value) {
        int min=value;
        if(!st.isEmpty()){
            min=Math.min(value,st.peek()[1]);
        }
        st.push(new int[]{value, min});
    }
    
    public void pop() {
       st.pop();
    }
    
    public int top() {
        return st.peek()[0];
    }
    
    public int getMin() {
        return st.peek()[1];
    }
}

 */

 ------implemented using 2 stacks--------
 class MinStack {
    
    Stack<Integer>st1=new Stack<>();
    Stack<Integer>st2=new Stack<>();
    public MinStack() {
        
    }
    
    public void push(int value) {
        st1.push(value);

        if (st2.isEmpty() || value <= st2.peek()) {
            st2.push(value);
        }
    }
    
    public void pop() {
        int val = st1.pop();

        if (val == st2.peek()) {
            st2.pop();
        }
    }
    
    public int top() {
        return st1.peek();
    }
    
    public int getMin() {
        return st2.peek();
    }
}

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack obj = new MinStack();
 * obj.push(value);
 * obj.pop();
 * int param_3 = obj.top();
 * int param_4 = obj.getMin();
 */

Single stack of pairs: \(O(1)\) per operation, \(O(n)\) space.
Two stacks: \(O(1)\) per operation, \(O(n)\) space.
